# Product

Product decisions live here and change only through a pull request merged by the
human (the product gate). They are written by `/discover`.

| File | Content | Created by |
|---|---|---|
| `vision.md` | Who the product is for, the problem, success, principles, non-goals | `/discover vision` |
| `story-map.md` | User activities in order, and the user actions under each | `/discover map` |
| `roadmap.md` | Releases as slices of the map: Now, Next, Later. No dates | `/discover release` |

These files do not exist yet: the first run of `/discover` creates them.

In GitHub: an epic per activity, a milestone per release, a user story per action.
Only the release being built is broken down into issues. Later releases stay as
titles until they are next.
